# ZeitVez — demonstração

Esta é a **vitrine do ZeitVez**: um site de demonstração, só para ver como o produto funciona, sem instalar nada e sem criar conta.

O ZeitVez é um sistema para **salões de beleza e barbearias**: cada negócio ganha um site próprio, com agendamento online, e um painel para acompanhar a agenda.

## Como ver a demonstração

Abra no navegador: **https://henriquezeitz.github.io/ZeitVez-demo/**

- A página inicial é o site do ZeitVez. Em **Demonstração**, clique em **Ver site** para abrir o site de um dos três negócios de exemplo (Studio Aurora, Barbearia Navalha e Espaço Lumi). Eles usam o mesmo sistema, só mudam as cores, as fontes e o conteúdo.
- Em cada site dá para **agendar um horário**, entrar na conta de exemplo e ver o painel do dono e do profissional.
- O botão **Telas**, no canto da página, lista todas as telas para você pular direto para a que quiser.
- Também dá para baixar esta pasta e abrir o `index.html` no computador, sem internet.

## O que é de verdade e o que não é

- **Os dados são fictícios.** Nomes, telefones, e-mails e preços foram inventados para a demonstração.
- **Nada é enviado nem salvo.** Formulários e botões só mostram como a tela se comporta; ao enviar, aparece um aviso e a próxima tela abre.
- **Esta pasta é uma cópia gerada** a partir do produto real. Ela não é editada à mão aqui: quando o produto muda, a cópia é gerada de novo.
